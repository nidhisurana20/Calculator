# Calculator

A simple command-line calculator written in Python. Supports addition,
subtraction, multiplication, division, exponentiation, and square root,
with basic error handling (divide-by-zero, negative square roots, bad input).

## Usage

```bash
python3 calculator.py
```

Follow the on-screen menu to pick an operation and enter numbers.

## Tests

```bash
python3 -m unittest test_calculator.py -v
```
